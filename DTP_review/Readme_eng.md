# Road Traffic Accident Analysis

## Project Description

This project focuses on analyzing road traffic accidents (RTA) using geospatial and tabular datasets.  
The goal is to explore data patterns, test hypotheses, and visualize key insights.

---

##  Key Steps

- Loading and processing data in **GeoJSON** format  
- Performing **data preprocessing**, **EDA**, and **correlation analysis**  
- Formulating and testing **three hypotheses**  
- Visualizing findings in **Yandex Datalens**

 View the interactive dashboard here:  
[**Datalens Dashboard**](https://datalens.ru/eox4ak8npuqmz)

---

## Technologies Used

- **Python:** geopandas, json, seaborn, plotly, matplotlib, pandas  
- **SQL**  
- **Datalens**

---

##  Project Aim

To identify key patterns and factors influencing the occurrence and severity of road traffic accidents,  
while showcasing data analysis, hypothesis testing, and visualization skills.
